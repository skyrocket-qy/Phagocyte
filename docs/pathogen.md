# 《Project: Phagocyte》病原體圖鑑與免疫對抗規格書 (Pathogen Codex & Immunology Mechanics)

---

## 1. 設計願景：真實微生物生理機制遊戲化

在《Phagocyte》中，敵人不是千篇一律的換皮小怪，而是嚴格依據**真實微生物學、病毒學、真菌學與病理學**設計的病原體。每種病原體均具備獨特的致病機制、逃逸手段與弱點克制，使玩家在對抗中自然領悟人體免疫對抗的生物學原理。

```mermaid
flowchart LR
    A["病原體侵入 (Invasion)"] --> B["特異性逃逸機制 (Immune Evasion)<br>生物膜、抗原漂移、蠟質壁、MHC隱匿"]
    B --> C["免疫武器克制 (Immunological Counter)<br>活性氧破盾、廣譜破膜、巨噬吞噬、超武處決"]
    C --> D["裂解為 ATP 與抗原碎片<br>(Digestion & EXP)"]
```

## 2. 病原體六大門類圖鑑 (The 6 Pathogen Taxa)

遊戲中實裝了 20 餘種經典病原體，涵蓋人體微觀戰場面臨的所有威脅形態：

### 2.1 革蘭氏陽性與陰性細菌 (Bacteria)

| 病原體名稱 | 代碼識別 | 形態與顯微特徵 | 真實致病機制與遊戲 AI 行為 | 免疫對抗與克制弱點 |
| :--- | :--- | :--- | :--- | :--- |
| **金黃色葡萄球菌<br>(Staph)** | `staph` | 亮黃色葡萄串狀球菌集群。 | **凝固酶與纖維蛋白護盾**：自帶一層纖維蛋白抗體護盾（`FibrinShield = 1`），抵擋第一次任何傷害；習慣 3～5 隻抱團推進。 | 使用【活性氧射流】或酸蝕 DoT 迅速融化護盾；亦可直接以巨化阿米巴偽足強行吞入。 |
| **綠膿桿菌<br>(Pseudomonas)** | `pseudomonas` | 藍綠色桿狀菌，周身散發螢光綠色素。 | **藻酸鹽生物膜 (Biofilm)**：移動路徑上留下一灘黏稠生物膜酸蝕爛泥，降低玩家移速並持續腐蝕護甲。 | 避免直線追擊；利用【補體瀑布】遠端引爆或利用穿孔長矛跨距離狙殺。 |
| **大腸桿菌<br>(E. Coli)** | `e_coli` | 具備周生鞭毛的短桿菌。 | **鞭毛高速游動與內毒素**：直線游動速度極快，死亡時向外噴出微量內毒素（LPS）震退周遭細胞。 | 預判衝鋒路徑，利用【偽足猛擊】擊退或利用 Y 型抗體遠端自尋制導。 |
| **幽門螺桿菌<br>(H. Pylori)** | `h_pylori` | 具備多根單極鞭毛的螺旋狀桿菌。 | **尿素酶中和抗酸圈**：自帶鹼性中和防護罩，螺旋鑽擊穿刺細胞膜；免疫常規酸液 DoT。 | 需使用高初速物理穿刺（如穿孔素長矛）或直接接觸破壞螺旋結構。 |
| **結核分枝桿菌<br>(Mycobacterium TB)** | `tb` | 細長抗酸性桿菌，壁厚。 | **分枝菌酸蠟質外壁**：極高護甲（高減傷），常規酶解無效；死亡時形成「乾酪樣壞死」凝塊。 | 利用【超氧化利維坦】或高階超武強行破壁，普通小抗體難以擊穿。 |
| **炭疽芽孢與桿菌<br>(Anthrax)** | `anthrax_spore` | 具備折光性的厚壁休眠卵形芽孢。 | **芽孢復甦機制**：平時處於休眠高防態；受創後活化裂解為高毒力的炭疽桿菌，移速與傷害飆升 $150\%$。 | 在芽孢活化前直接以超大體積一口生吞消化，阻止其進入繁殖態。 |
| **破傷風梭菌<br>(Tetanus)** | `tetanus` | 鼓槌狀帶端生芽孢的厭氧桿菌。 | **破傷風痙攣毒素脈衝**：週期性向四周釋放青紫色神經毒素脈衝（`TetanusPulse`），短暫致盲並減速玩家。 | 在其積蓄毒素脈衝時以高擊退武器打斷蓄力。 |

| **冠狀病毒<br>(S-Virus)** | `s_virus` | 具備鮮豔棒狀刺突蛋白的包膜球體。 | **刺突吸附與紅血球侵入**：碰撞時施加減速黏著效果；靠近場景紅血球時嘗試侵入並分裂複製。 | 在其侵入宿主紅血球前迅速使用【穿孔素長矛】擊碎其包膜。 |

| **狂犬病毒<br>(Rabies)** | `rabies` | 子彈狀包膜病毒。 | **嗜神經突觸瞬移**：具備極高加速度與短距離突刺瞬移，精準繞向玩家背後發動突襲。 | 保持游動走位；利用圍繞細胞的【受體棘刺陣列】造成接觸反傷。 |
| **人類免疫缺陷病毒<br>(HIV)** | `hiv` | 圓球狀慢病毒，表面 gp120 突刺。 | **逆轉錄酶干擾場**：週期性釋放干擾波，使玩家技能 CDR 暫時下降 20%。 | 優先集火斬殺的最高威脅高危輔助怪。 |
| **伊波拉病毒<br>(Ebola)** | `ebola` | 絲狀「6」字形或「U」字形長條。 | **微血管內皮崩解毒素**：身形狹長，游動時如蛇形鞭打，造成廣域物理揮擊傷害。 | 利用高額擊退阻斷其蛇形逼近。 |
| **水痘帶狀疱疹病毒<br>(Varicella-Zoster)** | `varicella_zoster` | 具備二十面體衣殼的雙鏈 DNA 病毒。 | **神經節潛伏突襲**：平時處於半透明隱匿潛行狀態，接近玩家時突發釋放神經電擊並現身。 | 依賴樹突狀細胞的【廣域抗原感應】或主動掃描提前破隱。 |
