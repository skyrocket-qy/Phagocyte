## Art guidance

- **Format**: square PNG with transparency. Recommended master **256×256**
  (Steam downsamples for overlay / library / community views).
- **Steam backend requires two icons per achievement**: Achieved + Unachieved.
  Suggested pipeline: draw the full-color master, then derive the unachieved
  variant (grayscale + 50% brightness) — the in-game gallery already renders
  locked cards dimmed the same way, so both ends look consistent.
- **Style**: dark microscope background + fluorescent subject, to match
  `assets/sprites/ui/menu/background.jpeg`. Keep the subject centered with
  ~16px safe padding so small-size rendering stays readable.
- **All-ages appropriate** (Steam review rule). No gore close-ups.

## Steam Partner upload checklist

1. App Admin → Achievement Configuration → one entry per API Name above
   (must match exactly, case-sensitive).
2. Upload Achieved + Unachieved icons, fill Display Name / Description
   (localizable — keep in sync with `assets/data/achievements.json`
   title/desc keys and `assets/translations/translations.csv`).
3. Publish changes. Until published, `GetAchievementIcon` returns handle 0
   and the game keeps showing the local file / emoji fallback.
4. Verify in-game via `SteamBridge.PullUnlocked()` round-trip; the gallery
   detail panel shows the API Name under each achievement for visual audit.

## Placeholder behavior (until art lands)

`AchievementGalleryView` loads `image_path` via `ResourceLoader.Exists()`:
file present → `TextureRect`; missing → emoji fallback (`icon` field) on a
category-tinted plate. Dropping a PNG into this folder is enough — no code
change needed. The `.import` sidecars are generated by the editor on scan.
