# Game Visual Evaluation Skill Resources

This directory and its siblings contain references, checklists, and automation tools for visual inspection and regression testing in Project: Phagocyte.

## Contents

- **`../SKILL.md`**: Main operational runbook for executing visual evaluations, before/after captures, diff generation, and AI reviews.
- **`../scripts/capture_diff.py`**: Automated visual regression comparator (pure Pillow) that produces side-by-side composites and pixel difference maps.
- **`../references/visual-checklist.md`**: Comprehensive quality criteria and diagnostic matrix for Phagocyte's Confocal Microscopy / Bio-Fluorescence aesthetic.
- **`../references/capture-catalog.md`**: Catalog of all capturable visual surfaces with exact godot-ai MCP recipes and test harness targets.
